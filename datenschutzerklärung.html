Beim Besuch dieser Website werden keine personenbezogenen Daten ohne Ihr Wissen gespeichert, außer jene, die Ihr Browser automatisch an uns übermittelt (IP-Adresse, Browsertyp).

2. Eingebettete YouTube-Videos

Diese Website nutzt Plugins des Anbieters YouTube (Google Ireland Limited). Wenn Sie eine Seite mit einem eingebetteten Video besuchen, wird eine Verbindung zu den YouTube-Servern hergestellt. Dabei wird dem YouTube-Server mitgeteilt, welche unserer Seiten Sie besucht haben. Sollten Sie in Ihrem YouTube-Account eingeloggt sein, ermöglichen Sie es YouTube, Ihr Surfverhalten direkt Ihrem persönlichen Profil zuzuordnen.

3. Google Fonts

Diese Website verwendet Google Fonts zur einheitlichen Darstellung von Schriftarten. Beim Aufruf einer Seite lädt Ihr Browser die benötigten Web Fonts in Ihren Browser-Cache, um Texte korrekt anzuzeigen. Zu diesem Zweck muss der von Ihnen verwendete Browser Verbindung zu den Servern von Google aufnehmen.
